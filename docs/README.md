## 一、理论摘要

**可计算时间投资理论（Computable Time Investment Theory, CTIT）** 提出：时间管理的本质是对「时间投入的回报」做量化排序，而非对「重要 / 紧急」做主观判断。

### 三个量纲统一的时间参数

| 参数 | 定义 | 量纲 |
|------|------|------|
| T_impact | 影响时间：完成事务带来的总影响（含连锁效应与长期价值） | 小时 |
| T_cost | 执行耗时：完成事务实际投入 | 小时 |
| T_remain | 剩余时间：距最佳执行窗口关闭 | 小时 |

三者统一为「小时」量纲，才具备可计算、可比较的前提。

### 核心定义

- **时间投资回报率**：`TROI = T_impact / T_remain`
- **优先级排序**：按 TROI 降序执行，使单位「剩余时间」产生最大「影响时间」。
- **偏置校准**：主观预估存在系统性偏差（普遍高估 / 低估），用 PI 控制器
  `T_impact_校正 = T_impact_原始 × (1 − Σ误差 × K_i)` 自动修正。

### 关键洞察

1. **P-only 稳态误差**：仅用比例校正（P）无法消除偏置，稳态误差 = `b/(1+Kp)`；必须引入积分项（I）才能收敛到零偏。
2. **四象限的局限**：经典「重要-紧急」四象限依赖中位数硬切分，丢掉连续性信息；TROI 保留连续量纲，排序更优。

## 二、实验数据（蒙特卡洛，可复现）

### 实验一：TROI 排序的决策质量

| 排序方法 | 平均总影响时间（h） | 相对提升 |
|---------|-------------------|---------|
| 随机排序 | 2,437.42 | — |
| 四象限分类 | 20,774.43 | +752%（vs 随机） |
| **TROI 排序** | **31,514.45** | **+51.7%**（vs 四象限） |

- Cohen's d = 0.946，p = 5.25×10⁻¹⁴¹
- 原始数据：`../sim/results/exp1_main_results.csv`、`exp1_stats.json`

### 实验二：PI 偏置校准

| 校准方式 | 早期偏置（h） | 稳态偏置（h） | 偏置消除率 |
|---------|-------------|-------------|-----------|
| 无校准 | +5.97 | +5.98 | 0.3% |
| P-only | +4.06 | +3.94 | 34.3% |
| **PI** | **+1.29** | **−0.005** | **100.1%** |

- PI vs P-only 稳态：d = 5.79，p = 3.26×10⁻¹⁵⁵
- 原始数据：`../sim/results/exp2_main_results.csv`、`exp2_stats.json`
